
# Wingo 1-Minute Prediction Bot

This Telegram bot uses real API data to make 1-minute Wingo predictions with features like:

- Multiple color and number predictions
- Confidence score
- Smart strategy and accuracy tracking
- Alert-style messages in Hindi-English

## Setup

1. Install requirements:
```
pip install -r requirements.txt
```

2. Replace `YOUR_BOT_TOKEN` and `YOUR_CHAT_ID` in `bot.py`

3. Run the bot:
```
python bot.py
```
